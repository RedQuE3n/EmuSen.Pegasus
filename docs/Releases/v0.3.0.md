A live shared notepad two people type into at once, CRDT-backed, where no party
may lose information.

**This release is MIT-licensed, every tab stop in both windows now announces
itself, and the binaries are built by a workflow instead of by hand.** The
protocol is untouched — `Hello` still says **4**, so a 0.1.0 and a 0.3.0 talk to
each other exactly as before.

**There is no 0.2.0, and it was spent rather than skipped.** It was tagged, its
build matrix named the `macos-13` runner image, and that image had been retired
on 4 December 2025. A retired label does not fail — the job queues forever — so
three platforms built, the fourth never started, and nothing was published.
`docs/Pegasus_Design.md` §15.4 is the account.

## What changed

**The licence is now MIT.** v0.1.0 was GPL-3.0-or-later, and it said so as a
consequence rather than a choice: Pegasus links `EmuSen.LunaP`, LunaP was GPL,
and this repository inherited the term without ever deciding it. LunaP re-decided
first and found nothing in its own dependency tree had been imposing copyleft
either. `docs/Pegasus_Design.md` §14 is the audit. **The v0.1.0 binaries stay
GPL-3.0-or-later** — a grant already made is not withdrawn by a later, looser
one, and source for them remains this repository at the `v0.1.0` tag.

**Accessibility.** Ten of the twenty tab stops across the two windows previously
announced as nothing at all to a screen reader, and every one that did announce
was a button reading its own caption back. All twenty now carry an accessible
name, asserted by tests rather than by inspection. The editor announces which
note is open — "Note: groceries" — and renames itself when you switch, so
changing notes is no longer silent. The status line and the buddy message
announce themselves as polite live regions, because both carried state in a
colour and a colour is precisely what a reader cannot pass on. Window padding
was set for the first time along the way. §13.

**The release is a workflow.** v0.1.0 was four `dotnet publish` runs on one Linux
laptop with nothing left behind to reproduce them. Each platform is now built by
the operating system it targets, from the tag, with the checksums generated over
the artefacts being uploaded. §15.

## Running it

**Linux** — extract and run:

    tar xzf Pegasus-0.3.0-linux-x64.tar.gz
    ./Pegasus-linux-x64/EmuSen.Pegasus

**macOS** — the app is **not signed or notarised**, so Gatekeeper will refuse it
on first launch, and the download will carry a quarantine flag. Clear it:

    tar xzf Pegasus-0.3.0-osx-arm64.tar.gz
    xattr -dr com.apple.quarantine Pegasus-osx-arm64/EmuSen.Pegasus.app
    open Pegasus-osx-arm64/EmuSen.Pegasus.app

**Windows** — the executable is **not signed**, so SmartScreen will show "Windows
protected your PC" on first run; the binary is reachable through *More info →
Run anyway*.

Signing on either platform needs a paid certificate from Apple or a Windows
code-signing CA. There isn't one, and saying so is better than leaving you to
discover it at the warning dialog.

## What was actually tested

Stated plainly, because this is an academic project and a release note that
implies more testing than happened is worse than one that admits the gap.

- The full suite passes: **160 tests**, headless, including UI tests driving a
  real Avalonia control tree.
- **The macOS and Windows binaries are now compiled on macOS and Windows** rather
  than cross-compiled from Linux, which is what the build matrix changed.
- **No binary in this release has been started by anybody.** Pegasus is a GUI, a
  CI runner has no display, and there is no `--help` path to exercise instead.
  This is a step back from v0.1.0, where the Linux build was launched by hand and
  checked as far as the sign-in window, and it is named here rather than left to
  be discovered.
- **No screen reader has been run against the accessibility work.** Every
  measurement is of Avalonia's automation tree, which is what a platform bridge
  reads — necessary, and not the same as Orca or NVDA reading it aloud.
- There is **no application icon** in any build. macOS shows the generic app
  icon. Nothing in the repository has ever had one.
- There is **no `linux-arm64` build**, so a Raspberry Pi cannot run this. Building
  from source on the machine works and is one `dotnet publish`.

## What the encryption is, and is not

Unchanged from v0.1.0 and repeated rather than linked, because software that
ships crypto and is vague about it is worse than software that ships none.

Frames are sealed with AES-256-GCM under a key derived from a short spoken join
code by PBKDF2-HMAC-SHA256, **with a fixed salt** — both peers must reach the
same key from the code alone, with no round trip in which to agree a random one.
An attacker can precompute against the whole code space; the iteration count
raises the cost without changing the shape of the problem.

**This is a pre-shared key for two people on a private network.** It is not
protection against someone who watched the pairing, and there is no forward
secrecy on that path. The threat model is `docs/Pegasus_Sync.md` §5.

## Talking to a relay

Pegasus reaches a peer directly, or through **Chariot**, the relay — which never
holds a note and cannot read a word either party writes. Chariot 0.3.0 is
released alongside this at <https://github.com/RedQuE3n/EmuSen.Chariot/releases>,
and is MIT as of that version for the same reasons.

Both programs speak **protocol 4**, through `EmuSen.Pegasus.Core`, which is
**0.3.0** and MIT on nuget.org. The application version and the core's version
move independently: the core versions on the protocol, this versions on the
program.
